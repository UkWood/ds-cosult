# DS-консультант (ds-cosult)

Независимый проект исследования и возможной разработки AI Technical Consultant для технической документации МНПП «Сатурн».

## Текущее решение владельца — 18 ноября 2026 года

**ARCHITECTURE BASELINE APPROVED FOR LIMITED EXPERIMENTAL CODING.** Владелец завершил итерационные независимые архитектурные ревью и разрешил Merge исторического архитектурного PR #1 в `main`, затем **отдельную CODEX-сессию** для ограниченного локального стенда на двух объектах: **БКД-ПК-RF.2** и **СЛДКС-1**. Это разрешение **не** распространяется на публичный Production, Corpus Freeze, платные DeepSeek API-вызовы, автоматический Merge новых кодовых PR или запись в доверенный сайт.

Нормативные документы: [архитектурный baseline + R4-CR01](docs/decisions/DS-ARCH-BASELINE-01-OWNER-ACCEPTED-CODING.md), [фиксированный двухобъектный корпус](docs/corpus/DS-PILOT-01-TWO-ENTITY-SOURCE-SCOPE.md), [задание CODEX на работающий локальный прототип](docs/tasks/DS-CODEX-01-TWO-ENTITY-LOCAL-PROTOTYPE.md). Предыдущие запреты Merge/DS-02 в исторических текстах относятся к периодам **до данного прямого решения владельца**. Новая реализация должна вестись в отдельной ветке и Draft PR от принятого `main`.

**Критичное R4-CR01:** на `ADMITTED` фиксируются точный исходный вопрос и контекст; после P1 **сервер** окончательно формирует, проверяет и замораживает полный `QuestionNeeds` до финальной проверки; зависимости устанавливаются по проверенным источникам до `FinalStatus`; ни P1, ни P2 не могут исключить обязательную часть исходного вопроса. Неопределённость покрывается явным `unresolved`, не выдуманным полным ответом.

**Первый запуск:** Python/FastAPI, локальный веб-чат `127.0.0.1:8765`, source-cited P0 + mock P1/P2, **0 реальных/платных вызовов DeepSeek без отдельного числового GO**. Два реальных исходника по одному immutable Git commit; PDF пока metadata-only до подтверждения реальных байтов/страниц.

## Назначение репозитория

**Этот репозиторий — долговременная память проекта и единственный утверждаемый источник проектной истории.** Здесь ведутся требования, журнал решений, утверждённые протоколы, состояние работ, задания, результаты экспериментов, приёмочные отчёты и позднее исходный код. Каждое важное решение должно иметь дату, статус, основания и ссылку на соответствующий документ.

## Текущий API-провайдер

**Прямой DeepSeek API** (решение владельца, ADR-0004). Base URL: `https://api.deepseek.com`; модель `deepseek-flash`. AI Tunnel отклонён и хранится только как историческое решение ADR-0003, SUPERSEDED. Возможности нативного API должны пройти conformance test до реальных испытаний.

## Основные правила

- Проект полностью **независим от NEW RAG** (`UkWood/LLM-RAG-chat-bot`). Перенос решений и кода без отдельного разрешения запрещён.
- Репозиторий `UkWood/Saturn-Main-Site` используется строго **READ-ONLY**.
- Текущий этап: **DS-PILOT-01 — ограниченный локальный экспериментальный кодинг** после принятого архитектурного baseline. Исторический DS-01C и независимые ревью сохранены ниже и в журнале.
- Владелец **прямо разрешил Merge архитектурного PR #1 и отдельное ограниченное экспериментальное кодирование**. Merge будущих кодовых PR, Production, Corpus Freeze и платные DeepSeek-вызовы требуют отдельных разрешений.
- Код и материалы оцениваются в отдельной ветке и PR; принятые решения фиксируются после приёмки.
- Утверждения о свойствах техники должны иметь привязку к версии доверенного первоисточника.
- **Внимание:** сейчас репозиторий публичный. Секреты, сырые материалы с ограниченным доступом, закрытые Core-вопросы и Ground Truth нельзя размещать в публичных коммитах.
