# DS-PILOT-01 в Linux / WSL2

Нужны Git и Python 3.11 или новее с модулем venv. Все команды выполняются из Bash.

```bash
git clone --branch codex/ds-pilot-01 https://github.com/UkWood/ds-cosult.git
cd ds-cosult
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt

git init ../saturn-pilot-source
git -C ../saturn-pilot-source fetch --depth=1 https://github.com/UkWood/Saturn-Main-Site.git 084d759487bfab6e111549c9b5469711ac5fc13e

python -m ds_pilot import ../saturn-pilot-source
SATURN_SOURCE="$(realpath ../saturn-pilot-source)" python -m pytest -q
python -m ds_pilot serve
```

Откройте [локальный чат](http://127.0.0.1:8765) в браузере. В WSL2 можно открыть этот адрес в Windows. Задайте «Какой диапазон температуры у БКД-ПК-RF.2?», затем «Какое питание постоянного тока у него?» в том же чате. Задайте «Что такое СЛДКС-1?» и попробуйте «Сравни температуру эксплуатации БКД-ПК-RF.2 и СЛДКС-1». В частичном ответе будет значение для БКД и пояснение о пробеле данных для СЛДКС-1. Под ответом видны ссылки на закреплённые исходники. Раздел «Проверка источников и охвата» содержит локаторы, хеши и диагностику неподтверждённых пунктов.

Для CLI используйте отдельное локальное хранилище, если веб-чат уже активен. Так вопросы CLI не займут его квоту.

```bash
python -m ds_pilot --data .pilot/cli import ../saturn-pilot-source
python -m ds_pilot --data .pilot/cli ask 'Какая масса БКД-ПК-RF.2?'
python -m ds_pilot --data .pilot/cli ask 'Где руководство по эксплуатации СЛДКС-1?' --json
```

После установки и импорта сервер и CLI работают офлайн. Переход по ссылке на GitHub или сайт Saturn выполняет браузер. Ключ API не нужен. При ошибке импорта проверьте точный SHA в команде fetch и повторите импорт. При занятом порте используйте `python -m ds_pilot serve --port 8766`. Если WSL2 не пробрасывает localhost в Windows, проверьте доступ из WSL командой `curl http://127.0.0.1:8765/` и настройки localhost forwarding.

Свежий браузер не наследует историю. Технические ссылки диалога истекают через 15 минут, серия вопросов сбрасывается через 30 минут бездействия. Для одного локального оператора действует лимит 20 принятых вопросов за календарный день по Москве. Перед Q6–Q10 интерфейс покажет время ожидания. После Q10 требуется пауза до сброса серии.

SQLite-файл и копии источников находятся в исключённом из Git каталоге `.pilot`. База хранит исходные вопросы и ответы локально. Записи старше 30 дней удаляются при следующем вызове движка. Используйте синтетические вопросы для демонстрации.
