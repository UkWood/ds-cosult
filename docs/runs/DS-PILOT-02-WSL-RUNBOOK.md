# DS-PILOT-02 в WSL2

В уже клонированном репозитории выполните следующие команды в Bash. Для GitHub нужен доступ на чтение к обоим репозиториям. При запросе пароля Git воспользуйтесь входом через браузер командой `gh auth login --hostname github.com --git-protocol https --web`, затем выполните `gh auth setup-git`.

```bash
cd ~/ds-consult-validation/ds-cosult
git switch codex/ds-pilot-01
git pull --ff-only
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
```

Из каталога `ds-cosult` подготовьте соседний репозиторий Saturn и импортируйте корпус. Команды связаны, поэтому ошибка Git остановит импорт.

```bash
git init ../saturn-pilot-source &&
git -C ../saturn-pilot-source fetch --depth=1 https://github.com/UkWood/Saturn-Main-Site.git 084d759487bfab6e111549c9b5469711ac5fc13e &&
python -m ds_pilot import ../saturn-pilot-source
```

После успешного импорта можно запустить чат.

```bash
python -m ds_pilot serve --lab
```

Если Debian/Ubuntu сообщает об отсутствии ensurepip, установите пакет для выбранного Python через sudo, например `sudo apt install python3.14-venv` для Python 3.14, и повторите создание окружения. Облачная валидация использовала Python 3.12.

Откройте [локальный чат](http://127.0.0.1:8765). Спросите «Какая масса БКД-ПК-RF.2?», нажмите F5 и задайте «Какое питание постоянного тока у него?». При утрате cookie прочтите одноразовый код в терминале командой `cat .pilot/lab-recovery-code` и введите его в форму восстановления. Для чистого опыта используйте «Новый диалог». «Сброс лаборатории» очищает историю лабораторной сессии. Денежный журнал хранится отдельно. Для проверки прежних ограничений запустите `python -m ds_pilot serve`. Остановить сервер можно сочетанием Ctrl+C.

## Документация производителя

```bash
python -m ds_pilot pdf-inventory
python -m ds_pilot download-pdf --entity bkd
python -m ds_pilot download-pdf --entity sld
```

Загрузка направлена на адрес из закреплённой карточки. При недоступности сайта возьмите локальную копию соответствующего оригинала и заранее проверенный SHA-256. Пример команды со своими значениями:

```bash
python -m ds_pilot import-pdf /path/to/manual.pdf --entity bkd --expected-sha256 SHA256
python -m ds_pilot manifest
```

Перезапустите сервер после обновления корпуса. Вопрос о конкретной физической странице позволяет посмотреть подтверждённый текст цифровой страницы. Скан, неоднозначная схема или непроверенная ячейка не служат основанием для технического утверждения.

## DeepSeek по явному выбору владельца

Для P0 достаточно `serve --lab`. Для испытания P1 или P2 остановите сервер и запустите его из интерактивного терминала WSL:

```bash
python -m ds_pilot serve --lab --enable-deepseek
```

Сверьте действующие цены Flash на [официальной странице тарифов](https://api-docs.deepseek.com/quick_start/pricing/). Стартовая проверка ожидает стоимость миллиона токенов в USD в порядке cache miss, output, cache hit. Утверждённые значения — `0.30 1.20 0.006`. При изменении тарифа остановите эксперимент. Ключ вводится только в ответ на скрытый запрос терминала. В браузере выберите P1 или P2 и отправьте один вопрос. Режим, доступные попытки и резерв видны в лаборатории, сведения о конкретной попытке — в диагностике ответа. P0 и модельный маршрут сравниваются отдельными отправками.

Один консервативный резерв составляет $0.00708. На весь эксперимент разрешено до 12 попыток и до $0.10. Тайм-аут сохраняет риск списания, автоматического повтора нет. Общий SQLite-журнал находится в домашнем каталоге Linux-пользователя по пути `~/.local/state/ds-consultant/paid-budget.sqlite`. Используйте одного WSL-пользователя для всего эксперимента, включая разные клоны проекта. Удаление журнала или запуск из независимого дистрибутива лишает приложение общей истории. Учёт ведётся по usage и резервам. Фактическую сумму списания сверяйте в кабинете провайдера, где при наличии можно задать отдельный лимит.
