## B. Локальная лаборатория

POLICY_TEST сохраняет прежние лимиты, отдельная LAB-база поддерживает длительную серию, чтение истории, одноразовое восстановление доступа из терминала, новый диалог и явный сброс. Запрос и контекст сохраняются при допуске. Пропуск части вопроса P1 или выбор неподходящего ID в P2 проверяются на сервере. После падения процесса сохраняется ограда от повторной отправки.

В исходной версии F5 очищал экран, но при сохранённом cookie местоимение ещё разрешалось. Потеря cookie воспроизводила session_locked. В обновлённой версии Chromium 156.0.8078.79 прошёл пять F5, продолжение диалога, две вкладки, потерю уже отправленного ответа, повтор, рестарт сервера, потерю cookie, одноразовое восстановление, отказ старому cookie, обработку незавершённого запроса, сброс и новый диалог. Два допуска, одна имитация POST, ноль реальных POST. Проверено сохранение синтетического денежного журнала при сбросе. Защита от прокси опирается на loopback и проверку Host, Origin и прокси-заголовков; это локальный однопользовательский режим.

## C. DeepSeek и расходы

WSL-владелец запускает отдельный LIVE-процесс, сверяет пиковые тарифы и вводит ключ через getpass. Одно обращение P1 либо P2 допускается после денежного резерва, до POST фиксируется намерение отправки. Модель получает ограниченный пакет JSON. Валидатор связывает ID с исходными потребностями и доказательствами. Сервер рендерит ответ. Полные сериализованные запросы ограничены консервативным байтовым порогом. Точное число токенов можно сопоставить только с полученным usage.

Указанные суммы относятся к текущей работе в Codex. Удалённый биллинг и состояние отдельной WSL-машины владельца здесь недоступны. ## Регрессия PDF Evidence · ревью Draft PR #2

Вместо допуска всей страницы импорт теперь оценивает отдельные текстовые блоки. К цитате добавлены координаты в системе pdfplumber, порядковый номер блока, физическая страница, документ и версия извлечения. Изображения, повёрнутые подписи, линии рисунков и таблицы регистрируются как исключённые области. Цитата страницы может содержать несколько отдельных текстовых блоков. Для антенны 4G Div допускается явная связь в тексте либо однозначная строка с координатами ячеек. Для работы SIM требуется явное утверждение об одновременности и программном переключении. Эти два правила технических утверждений действуют только для утверждённых SHA-256 и страниц руководства БКД. Материал корпуса требует собственного доказательства.

### Обновление и проверка в WSL

Остановите текущий сервер через Ctrl+C. Если оригиналы уже импортированы, достаточно обновить ветку и запустить сервер. Блоки извлекаются заново из сохранённых PDF, существующие записи импорта используются повторно.

```bash
cd ~/ds-consult-validation/ds-cosult
git pull --ff-only
source .venv/bin/activate
python -m ds_pilot pdf-inventory
python -m ds_pilot serve --lab
```

Если оригиналы ещё не импортированы, из каталога проекта укажите реальные локальные пути:

```bash
python -m ds_pilot import-pdf /path/to/BKD.pdf --entity bkd --expected-sha256 030303812b4bd8dfc7e82fcd3ad4ef8493526549c7c90d033ce25b4f8b2fe83a
python -m ds_pilot import-pdf /path/to/SLDKS.pdf --entity sld --expected-sha256 f1436a93285cad9a201b6b387ed64a606ad2768cfc7ee70627c188411e9ce61f
SATURN_SOURCE="$(realpath ../saturn-pilot-source)" SATURN_BKD_PDF=/path/to/BKD.pdf SATURN_SLD_PDF=/path/to/SLDKS.pdf python -m pytest -q -s tests/test_pdf_sources.py
```

В выводе теста будут числа допущенных блоков по каждому оригиналу. `pdf-inventory` показывает исключения по физической странице. В лаборатории можно повторить вопросы «2 SIM карты могут работать одновременно?» и «К какому разъему подключается дополнительная антенна 4G Div?» и проверить фрагмент, SHA-256 и координаты в диагностике ответа.
