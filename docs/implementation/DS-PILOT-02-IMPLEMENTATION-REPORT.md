## B. Локальная лаборатория

POLICY_TEST сохраняет прежние лимиты, отдельная LAB-база поддерживает длительную серию, чтение истории, одноразовое восстановление доступа из терминала, новый диалог и явный сброс. Запрос и контекст сохраняются при допуске. Пропуск части вопроса P1 или выбор неподходящего ID в P2 проверяются на сервере. После падения процесса сохраняется ограда от повторной отправки.

В исходной версии F5 очищал экран, но при сохранённом cookie местоимение ещё разрешалось. Потеря cookie воспроизводила session_locked. В обновлённой версии Chromium 156.0.8078.79 прошёл пять F5, продолжение диалога, две вкладки, потерю уже отправленного ответа, повтор, рестарт сервера, потерю cookie, одноразовое восстановление, отказ старому cookie, обработку незавершённого запроса, сброс и новый диалог. Два допуска, одна имитация POST, ноль реальных POST. Проверено сохранение синтетического денежного журнала при сбросе. Защита от прокси опирается на loopback и проверку Host, Origin и прокси-заголовков; это локальный однопользовательский режим.

## C. DeepSeek и расходы

WSL-владелец запускает отдельный LIVE-процесс, сверяет пиковые тарифы и вводит ключ через getpass. Одно обращение P1 либо P2 допускается после денежного резерва, до POST фиксируется намерение отправки. Модель получает ограниченный пакет JSON. Валидатор связывает ID с исходными потребностями и доказательствами. Сервер рендерит ответ. Полные сериализованные запросы ограничены консервативным байтовым порогом. Точное число токенов можно сопоставить только с полученным usage.

| live_tests_not_run | true |
| usage-based_cost_estimate | $0.00, платных запросов из этой среды не было |
| unreconciled_at_risk_reservations | $0.00 |
| authorized_limit | $0.10 |
| Максимум попыток | 12 |
| Резерв перед попыткой | $0.00708 |

В офлайн-тестах подменён HTTPS-транспорт и использованы временные журналы. Проверены 12-я и 13-я попытки, смена процесса, конфликт доступа, неверный тариф, ошибки HTTP, тайм-аут, неизвестное списание, малформированные ответы, утечка ключа, повтор и сброс. Указанные суммы относятся к текущей работе в Codex. Удалённый биллинг и состояние отдельной WSL-машины владельца здесь недоступны. Журнал обеспечивает общий предел в рамках одной сохранённой установки Linux-пользователя. Оценка по usage отличается по назначению от выписки провайдера. Сопоставление 12 выбранных вопросов с реальным DeepSeek ожидает ручной WSL-запуск.
