# DS-CODEX-01 · отчёт для Architecture Session A

## Результат

Работающий loopback-пилот для БКД-ПК-RF.2 и СЛДКС-1. Источники индексируются локально после импорта двух Git blobs с проверкой пинов. В манифесте записаны commit, blob SHA и SHA-256 фактических байтов. Извлечённые Entity, Fact, Relation и метаданные документов представлены в каталоге, записи индекса и журнал запросов хранятся в SQLite. Цитаты ведут на закреплённый Git commit и включают точный YAML-локатор или строку Markdown. Ссылки на PDF публикуются как метаданные.

При допуске движок записывает оригинал, исходные интервалы, контекст, версии политики и источников. После тестового P1 сервер самостоятельно восстанавливает обязательные части вопроса и фиксирует хеш полного списка. P2 получает уже фиксированный список и идентификаторы проверяемых кандидатов. Пропуск, подмена хеша и неизвестный идентификатор диагностируются. Единственное реализованное условное ребро связывает подтверждение серии М2 с её составом в той же доказанной области применимости. При пропуске предпосылки зависимый состав снимается до выбора статуса. Совместимость двух объектов остаётся неподтверждённой.

Два источника импортированы из read-only Git-репозитория. CLI выдал массу контроллера с локатором `mass_kg` и назначение системы с локатором `body:L28`. Тесты включают P01–P14, 12 составных запросов, пропуски P1/P2, условную зависимость, истечение контекста, приватность сессий, повтор запроса, повреждённый blob, конфликт, неподтверждённые клеммы, ограничения тела, квоты и тестовый лимит провайдера. В отдельном тесте исходящее соединение запрещено на уровне socket. Ключи и платные вызовы DeepSeek не использовались.

Chromium через Playwright отправлял реальные вопросы из формы и проверял текст, состояние ответа, количество ссылок и наличие панели доказательств. ## Ограничения и открытые пункты

- **Blocker для передачи на ревью.** GitHub API заблокирован средой. Уже отправленная ветка подходит для создания Draft PR через GitHub с доступом на запись.
- **Important, распознавание.** Локальная русская грамматика покрывает проверенные формулировки и известные варианты идентификаторов. Свободный синтаксис, эллипсис, исправление более сложных референтов, полное морфологическое сопоставление и общий граф зависимостей требуют дополнительных контрактных тестов. В текущем пилоте обрабатывается узкая условная конструкция М2.
- **Important, доказательная база.** Обработаны только два файла сайта. Для PDF доступны документные ссылки. Содержимое, физические страницы, таблицы и схемы не импортированы. Конфликт испытан синтетически, дополнительных утверждений о пригодности и составе между объектами нет.
- **Important, эксплуатация.** Один loopback-оператор и один активный чат, календарь Europe/Moscow выбран для локального запуска. При прерывании процесса между допуском и записью ответа строка остаётся незавершённой. Автоматического повтора нет, для нового пробного запуска можно выбрать отдельный путь данных. Публичная IP/NAT-политика, шифрование журнала, администраторские инструменты и восстановление аварийного состояния остаются за пределами этой реализации.
- **Important, провайдер.** P1/P2 используют только тестовые функции. Лимит слотов и счётчики токенов синтетические. Маршрут DeepSeek задан как отключённый дескриптор без HTTP-транспорта, реального токенизатора и USD-резерва. Моделируемый тайм-аут фиксирует попытку, а повтор запроса возвращает сохранённый ответ.
- **Minor, проверка окружения.** Linux/Python 3.12 проверены фактически. Запуск на машине владельца в WSL2 ещё предстоит. В тестах есть предупреждение Starlette о переходе `TestClient` на httpx2. Реальный Chromium подтвердил отображение синтетических примеров. Журнал приложения фиксирует только подготовку ответа к выдаче через ASGI.
