# ADR-0001 — Независимость DS-консультанта и долговременная память

Дата: 2026-11-17. Статус: ACCEPTED — решения владельца.

## Контекст
Исследуется альтернативный технический консультант на DeepSeek API, отдельный от действующей инициативы NEW RAG. Владелец создал `UkWood/ds-cosult` и прямо определил его долговременной памятью проекта.

## Решение
1. Проект и его репозиторий самостоятельны.
2. `UkWood/Saturn-Main-Site` — только чтение; `UkWood/LLM-RAG-chat-bot` не изменять.
3. В `ds-cosult` вести требования, историю, решения, статусы, задания, отчёты и исходный код.
4. Изменения на рассмотрение оформлять отдельной веткой/PR; Merge только после отдельного явного одобрения.
5. Не публиковать закрытый benchmark или ограниченные первоисточники в PUBLIC репозитории.

## Следствия
Каждая новая архитектурная сессия читает проектные документы GitHub перед продолжением работ. Публичная часть не содержит секретов и скрытой разметки финального тестирования.
