# ADR-0002 — Comparative DeepSeek Experiment: DS-01 v0.1

Дата: 2026-11-17. Статус: APPROVED — прямое утверждение владельца DS-01 v0.1.

## Исследовательский вопрос
Может ли официальный DeepSeek API с корректно организованными знаниями обеспечить качество технических консультаций на уровне DeepSeek Web или выше?

## Утверждённые варианты
- W: DeepSeek Web Reference — ручной сравнительный эталон пользовательского качества.
- A: DeepSeek API App-Experience — `deepseek-flash`, thinking, встроенные веб-инструменты.
- B: DeepSeek API + Entity-Centric Conversational RAG — доверенный retrieval, досье, Context Planner, Evidence Verification.
- C0: API без внешних знаний — диагностический контроль.
- B-text/B-entity — контролируемая абляция структуры знаний внутри B.

## Два режима оценки
Natural Workflow — варианты со штатными возможностями, пользовательское качество. Controlled Comparison — одинаковые факты/источники/модель/лимиты, различается организация контекста. Не сводить два режима к одному рейтингу.

## Масштаб
Pilot 12; Core 60 по 12 категориям (по 5); Repeatability 12×3; 8 многошаговых диалогов; 12 документных объектов / 24 мультимодальных задачи.

## Обязательные измерения
Техническая правильность, понимание намерения и сущности, полнота, grounding, точность ссылок, понятность, качество уточнений и диалога, PDF/схемы, стоимость, latency, надёжность. Строго отдельно учитывать ошибки, неподтверждённые утверждения и необоснованные отказы.

## Протокольное ограничение
Запрещён преждевременный DS-02 coding. Сначала проверенные источники и эталоны, после Pilot — final freeze перед Core. Главная цель — честный выбор архитектуры, не заранее определённая победа B.
