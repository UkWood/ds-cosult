## Границы пилота

- **БКД-ПК-RF.2.** Полное досье, 4 уникальных PDF, 80 страниц и исходная карточка. Три запуска через обычный CLI проверили одну и ту же серверно сверенную строку РЭ о массе. Вопрос о массе дал подтверждённый ответ; вопрос о массе и хранении дал подтверждённую часть и отметил пробел; вопрос о гарантии дал сообщение о недостаточности.
- **СЛДКС-1.** Неполнота родительского корпуса фиксируется отдельно, реестр доступен. Полная область содержит десять исходных страниц сайта и десять уникальных PDF на 403 физических страницах. Только страницы сайта занимают 103 443 байта при mock-пределе 64 000. Это наблюдение о прежнем mock-ограничителе, а не измерение токенов DeepSeek. Явный офлайн-режим `--reference-only` отправил карточку и закреплённое 83-страничное РЭ одним mock-вызовом. Прочие источники отмечены как вне запрошенной области; полная область не сужается автоматически. Максимальные параметры модели и бюджета прежние.
- **Другие сущности.** Проверены ссылки по всему действующему исходнику сайта. Расширение пилотного реестра досье остаётся отдельной работой по применимости выпуска, состава и связи каждой карточки с оригиналом. Внешний реестр деклараций обнаружен и отмечен как источник без разрешения на загрузку.
- **Покрытие ответа.** Подтверждение основано на точной строке оригинала, странице и области. Для произвольного технического вопроса автоматический способ независимой проверки ещё отсутствует. Решение о live или публикации требует отдельной авторизации.

## Воспроизведение

Утилиты: Python с `requirements-dev.txt`, curl, Git, Poppler, `prlimit`. `SATURN_SOURCE` указывает на закреплённый checkout `084d759487bfab6e111549c9b5469711ac5fc13e`, `DS_DC_CACHE` — на кэш аудита. Для старых тестов `SATURN_BKD_PDF` и `SATURN_SLD_PDF` указывают на оригиналы из кэша.

```sh
python -m ds_dc.pdf_audit --site "$SATURN_SOURCE" --cache "$DS_DC_CACHE"
python -m ds_dc.pdf_tables --cache "$DS_DC_CACHE"
python -m ds_dc --site "$SATURN_SOURCE" --cache "$DS_DC_CACHE" --reference-only \
  --question 'Что такое СЛДКС-1?'
python -m pytest -q
```

Оригиналы и внутренние receipts остаются вне Git; сеть используется только для аудита ссылок издателя. Ссылки других форматов проверяются с HEAD и ограниченным fallback GET. Результат такой проверки характеризует HTTP-доступность, а не содержимое или безопасность файла. В состав опубликованных исходников включены `src`, `public`, ссылки структурных полей карточек и публичные ресурсы из дерева Git. Архив `Old_Site`, примеры в документации разработки и ссылки, генерируемые динамически без литерала или структурной записи, не входят в этот аудит. URL с одинаковыми байтами считаются отдельными ссылками; хеши позволяют выделить повторы.

## Оставшиеся вопросы

- **IMPORTANT** · Полный контекст СЛДКС-1 и сравнение двух досье превышают неизменённый mock-лимит. Для будущей live-проверки нужен измеренный и утверждённый бюджет контекста или явная область запроса. Это независимое ограничение.
- **IMPORTANT** · Выборочные таблицы и разметка OCR отмечены в реестре. Нужна предметная сверка таблиц, схем и сканов с оригиналами. Docling и OCR не запускались.
- **IMPORTANT** · Для публикации нужен независимый механизм подтверждения остальных технических утверждений и контролируемый live-прогон. Успех mock не подтверждает доступность сервиса, live wire или качество модели.
- **MINOR** · Для списка битых ссылок требуется решение владельца сайта. Исключённый УКСЛ отмечен отдельно и не требует восстановления.

## Фактические показатели аудита

- **730 уникальных ссылок** · 229 PDF и 501 файл или ресурс иного типа. Из них 729 привязаны к разрешённому издателю. Ссылки на архивное дерево, исходные примеры и динамические URL без обнаруживаемой записи не проверялись.
- **224 PDF-ссылок** с полным пассивным извлечением (218 уникальных SHA-256, 9112 физических страниц по ссылкам). HTTP 404 у 3 PDF; один PDF требует проверки целостности. Один PDF исключён владельцем без сетевой проверки. Для аудита крупных файлов применены отдельные пределы 64 МБ и 750 страниц, с пакетной обработкой больших PDF. Runtime оставляет прежние пределы PDF и DeepSeek.
- **Текст и таблицы.** OCR-сверка отмечена у 57 PDF. Выборочная проверка pdfplumber подтвердила структурно полные сетки у 23 PDF. У 185 PDF выборка требует сверки разметки или Docling, у 16 не обнаружено сигнала таблиц. Успешная извлечённая сетка подлежит проверке по оригиналу. На остальных страницах анализировались признаки расположения текста, а не точность читаемого значения в каждой ячейке.
- **Иные форматы.** HTTP-доступны 479 ресурсов, 20 вернули 404 и один служебный ресурс вернул 403. Для внешнего ресурса без разрешения доступность остаётся непроверенной.
