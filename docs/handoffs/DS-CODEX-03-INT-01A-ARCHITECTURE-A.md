## Версии и пример

Экспериментальный wire namespace `experimental/ds-int-01a/1`, extraction `exact-regions/1`, parser `pdfplumber/0.11.9+pdfminer.six/20251230`. Доступные состояния используют названия DS-EC-02, но экспериментальный экспорт не претендует на полную canonical wire-совместимость. Coverage receipt полного корпуса и canonical атрибутный словарь отложены. Нормативные контракты DS-EC-02 §2 и §8, DS-EC-03 §10, DS-EC-04 §14 и DS-EC-05 §13 сохраняют силу. DS-EVIDENCE-10/11 использованы как постановка регрессионных сценариев.

Пример SYNTHETIC_ONLY из теста реального парсера — физическая страница 2, таблица 1, строка 2, столбец 2, literal `Hours`, quote SHA-256 `21e8492938abc179410c21f3598f141c4c59a8bf2d3b4e475b7d83e10adfc00f`. Координаты берутся из сетки. Для этого заголовка есть `header_association_unverified`, scope остаётся неизвестным, статус локатора `locator_verified`.

SHA-256 входного approved manifest — `78517ce8afca16bd4842df15f33685053261d3a49f5f5d7da6a395724e7b4ad6`. SHA-256 выходного `manifest.json` облачного прогона — `97b1163196daa8296b307ff9248cbcc38e67ded6dce8ff321d24724706dad97b`. Проверка всех трёх файлов против `SHA256SUMS` прошла. Для обоих отсутствующих документов записан `blocked/source_unavailable`, код CLI 1. В этом запуске `bytes_verified=0`, `exact_locator_proof=0`, `published_verified_claims=0`.

## Проверки и ограничения

`SATURN_SOURCE=/tmp/ds-int01a-saturn /tmp/ds-int01a-venv/bin/python -m pytest -q -rs` на Python 3.12.14 — **107 passed, 1 skipped**. Из них 9 новых SYNTHETIC_ONLY тестов. Пропуск относится к существующему тесту двух оригинальных PDF. Есть предупреждение Starlette о `httpx` в TestClient. Проверено извлечение физической страницы и сетки из синтетических PDF. Русскоязычные примеры, scope, значения и повреждённая геометрия проверяются контролируемыми parser fixtures. Для cloud-прогона реальный объём извлечения Saturn PDF и разрешимость карточек остаются неизвестными.

Извлечённые блоки и ячейки отражают текстовое представление parser. Многострочные, объединённые и продолженные таблицы, смысловые зависимости между сноской и значением, рисунки и схемы требуют визуальной проверки. Свободный текст сохраняется без автоматического утверждения, к какому изделию он относится. Поиск ограничен точным scope, порядок shortlist совпадает с порядком ledger, без семантического ранжирования. В CLI нет чтения произвольных URL и нет клиентского пути для model/visitor JSON.

**DeepSeek POST — 0. Платные обращения — 0.** Рабочий код PR #2, runtime, провайдеры, CI и Saturn site remote не изменялись.
