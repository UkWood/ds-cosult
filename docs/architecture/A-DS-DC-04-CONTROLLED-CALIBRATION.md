# A-DS-DC-04 · Controlled Calibration

Architecture Session A утвердила операторский эксперимент для двух полных досье на базе R1 `a4bcd85c8d371306815fb8a9f9c11bc72a82ee3f`.

- CAL-01 / Q01 — БКД-ПК-RF.2, 4 PDF и 80 физических страниц. CAL-02 / Q02 — СЛДКС-1 full_available, 10 PDF и 403 страницы. Используются закреплённые вопросы, SHA канонического манифеста и R1 wire fingerprints. История пуста. Q10 вне допуска. [Freeze и wire](../reports/ds-dc-02/r1-calibration-sizing.json)
- Отдельный CLI-допуск `controlled_calibration` связывает чистый HEAD, манифест, точный wire, срок, тарифы, модель, run, аккаунт, проект, principal и общий приватный журнал. GO на одну попытку включает явное принятие остаточного финансового риска. Для Q02 требуется новый GO с подтверждением конкретного GO Q01, а в журнале — успешно рассчитанный Q01 с `stop` для той же учётной области и реализации.
- Резерв $0,33 на POST и $0,000225 за физическую страницу. Q01 — $0,348000, Q02 — $0,420675, всего $0,768675. Два POST расходуют два extended-слота общей кампании DC-02. Суммарно до 14 upload / 483 страницы, GET/List/DELETE и автоматических повторов 0. Общий бюджет $2,50, дополнительные $0,50 вне полномочий.
- Локальный резерв ограничивает решение об отправке. Внешнее начисление может превысить резерв. `REVIEWED_BOUNDS` и обычный допуск по доказанной границе сохраняют прежнее назначение. Обычные лимиты 128 000 / 256 000 действуют.
- При неопределённом исходе, ошибке HTTP, неполном usage, расходе сверх резерва либо finish отличном от `stop` платная серия блокируется с удержанием. Сбой проверки входа или истечение GO останавливает отправку. Частный журнал сохраняет телеметрию, исходный черновик с фильтрацией секретов, claims/locators и диагностику. Содержание provider reasoning и техническая память обычного диалога исключены из записи калибровочного ответа.
- Оператор сначала сверяет Q01 с выставленным начислением и эталоном. Решение о GO на Q02 остаётся у владельца. Обычные live-вопросы требуют отдельного допуска. [Порядок запуска в WSL](../runbooks/DS-DC-02-LIVE.md)
