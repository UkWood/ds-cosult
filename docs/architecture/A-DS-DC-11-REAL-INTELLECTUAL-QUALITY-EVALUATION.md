# A-DS-DC-11 · Real Intellectual Quality Evaluation

Architecture Session A утвердила закрытый эксперимент по оценке интеллектуального качества DS-консультанта. DC-04A готовит офлайн-интеграцию. Первый реальный Q01-N в DC-04B требует отдельного GO. DC-04C рассматривает дальнейшие вопросы по результатам.

У одного нативного вызова два результата измерения. A содержит исходный CandidateAnswer V2.1. B содержит ответ принятого детерминированного Evidence-First тракта. Эксперт проверяет A и B по одному независимому эталону. Ручной score не выводится из технического вердикта. Синтетический прогон измеряет интеграцию, а доступность источников, полезность, полнота, модальность и безопасность реального ответа оцениваются отдельно.

Логический wire связывает prompt, вопрос, пустую историю, реестр и порядок досье. Digest логического payload хеширует каноническое представление с placeholder slots. При подстановке handles каждое PDF-поле сверяется с SHA, TTL и привязкой. Digest фактического тела вычисляется на HTTP-границе. Обратная нормализация проверяет все остальные поля. Hold и usage учитываются отдельно от корректности кандидата.

Эксперимент сохраняет прежний Resolver, полный freeze, V2.1 prompt, верификатор, выдачу и лимиты. A/B экспорт содержит санитизированную техническую производную копию. Сырые ответы хранятся в приватном каталоге эксперимента. [Протокол приёмки и GO](../runbooks/ds-dc-04a/ACCEPTANCE.md)
