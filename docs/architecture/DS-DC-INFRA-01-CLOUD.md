# DS-DC-INFRA-01 — Cloud CODEX / Read-only Real Corpus Access

20.11.2026. Решение владельца: основная среда разработки DS-консультанта — облачный CODEX. WSL — частный архив предыдущей лаборатории и контролируемая live-валидация при необходимости.

Владелец установил причину прежнего 403: домен `www.mnppsaturn.ru` не был включён в allowlist облачной среды, отказ происходил на proxy tunnel. После изменения настроек владелец сообщил HTTP 200 и загрузку полного BKD PDF на 65 страниц (~3 МБ). Совпадение SHA-256 с лабораторным оригиналом пока не подтверждено в новой среде; DC-01 должен повторить pin/preflight. Это не новая проверка, выполненная Architecture Session A.

Разрешать лишь необходимые доверенные источники в рамках настроек CODEX: GitHub для `UkWood/ds-cosult` и read-only `UkWood/Saturn-Main-Site`, `raw.githubusercontent.com` при необходимости, `www.mnppsaturn.ru`/`mnppsaturn.ru` для оригиналов по подтверждённым ссылкам, `ukwood.github.io` для сверки canonical routes если требуется. Дополнительный доступ не означает разрешённость источника для D1. Не обходить TLS/proxy/allowlist, не следовать недоверенным redirect, не загружать произвольные URLs посетителя.

Старые пути WSL в v0.2 описывают историческую лабораторию; в облаке используются закреплённый Git и оригинальные PDF по ссылкам. Лабораторный архив, billing и cleanup остаются локальной задачей владельца, не блокируют DC-01. Сохраняется режим read-only сайта, отдельный NEW RAG, запрет изменения старых PR, платных вызовов, commit/push/PR/merge/deploy до отдельного GO. Native Web Search не разрешён в публичном консультанте. Никакие возможности облачного CODEX не расширяют разрешения runtime DeepSeek.
