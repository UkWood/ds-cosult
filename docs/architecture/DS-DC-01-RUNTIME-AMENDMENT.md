# DS-DC-01 — дополнение к DS-EC-02–05

В изолированном пути DS-DC-01 локальный resolver выбирает целое закреплённое досье до D1. D1 заменяет P1/P2 и обязательный Hybrid Evidence Context в этом пути. Сервер сохраняет полный исходный вопрос и его SHA-256. Пока полнота и технические утверждения ожидают независимой сверки, весь вопрос остаётся в серверном `unresolved`. Данные документов и прежние ответы имеют отдельные роли. Артефакт на выходе — маркированный проект ответа для оператора.

Для P0 доступна локальная навигация по каталогу. До публикации сохраняются требования к полноте, применимости, отказу и независимой проверке утверждений. Параметры D1 используются в локальном mock. Лимиты production и исторические контракты сохраняют прежнюю силу.

Правила доступности документов, полноты досье и покрытия вопроса уточнены в [DS-PDF-01-R1](DS-PDF-01-R1.md).
