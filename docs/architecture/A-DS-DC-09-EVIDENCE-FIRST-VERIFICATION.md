# A-DS-DC-09 · Evidence-First Verification

**Решение утверждено владельцем для DS-DC-03C.** В закрытом офлайн-тракте сервер определяет, какой материал допустимо включить в ответ. Генератор возвращает предполагаемые технические связи и запросы на выдержки.

Проверяются три свойства. Идентичность источника и совпадение фрагмента устанавливаются по оригиналу. Контекст и область применимости устанавливаются по геометрии, заголовкам, редакции и явной привязке к исполнению. Техническое утверждение подтверждается отдельным структурным правилом. Технические статусы сохраняются независимо от статуса выдержки и покрытия вопроса.

| Результат | Допуск |
|---|---|
| `supported` | Сборка утверждения из проверенных полей, с источником и областью применимости. Рискованные действия проходят отдельную политику. |
| `source_verified` | Целая исходная запись с атрибуцией и контекстом. Технический статус может оставаться `semantic_pending`. |
| `semantic_pending` | Нерешённая часть остаётся видимой. Подтверждённые сведения по другим частям сохраняются. |
| `contradicted` | Проверенный источник может быть показан отдельно. При разных значениях для одного доказанного параметра обе позиции получают источники, а сам параметр остаётся нерешённым. |
| `invalid` | Неверный элемент исключается. Ошибка версии, идентификатора или отпечатка запроса, структуры пакета либо уникальности ID блокирует пакет. |

Строки PDF сохраняют исходные заголовки, все ячейки, координаты, вертикальные объединения и геометрически близкие подписи и примечания. Непустой столбец неизвестной роли или геометрически неразрешённая ячейка запрещают техническое подтверждение. Для известного столбца исполнения требуется точное обозначение текущего изделия. Вхождение в досье разрешает чтение источника. Применимость технических сведений устанавливается отдельно.

Сервер допускает точно проверенное справочное цитирование без второго модельного вызова. Для потенциально опасных работ закрытая выдача может ограничиваться ссылкой и обращением к документации или поддержке. Покрытие исходных частей вопроса устанавливается независимой проверкой, привязанной к материалу. История этого тракта хранит только исходные вопросы сеанса и сохраняет нерешённые части.
