# DS-PDF-01-R1 · Доверенные PDF и частичное покрытие

Решения владельца от 20.11.2026 применяются к документному пути DS-DC. Эта поправка заменяет правило первоначальной приёмки DC-01 о блокировке досье при выпадении связанного PDF. Исторические протоколы и результаты тестов сохраняют свой контекст. Для публичного ответа действуют требования независимой верификации DS-EC-03 и DS-EC-05.

1. Устаревший УКСЛ СЛДКС по адресу `https://www.mnppsaturn.ru/photos/2278872612744825.pdf` имеет статус `EXCLUDED_BY_OWNER`. Он исключён из активного состава, запросов и подсчёта пробелов.
2. Доверенный PDF — исходник по утверждённой связи из закреплённого корпуса и одобренного HTTPS-источника. Поддерживаются проверка сигнатуры, целостности, лимитов, ошибок и количества физических страниц. Poppler извлекает текст пассивно. Аннотации, ссылки, действия открытия и навигация не являются самостоятельной причиной отказа. Аудит выборочно проверяет извлечённые таблицы по геометрии страниц. Для сканов предусмотрена отдельная очередь OCR.
3. Доступность файла, полнота ожидаемого корпуса, полнота выбранного досье и покрытие конкретного вопроса отражаются отдельно. Недоступный файл и причина записываются в диагностике, остальные утверждённые материалы доступны. Утверждённое контекстное окно и предохранители API сохраняются. Офлайн-оператор может явно выбрать область «основная карточка и закреплённое РЭ». Отбор виден в ответе и журнале.
4. Ответ строится из независимо подтверждённых частей. При полном покрытии показывается полный ответ, при частичном — подтверждённая часть и пробелы, без подтверждённых частей — сообщение о недостаточности. «Не выдумывай недостающие технические характеристики». Модельный кандидат маркируется отдельно и не подтверждает свои утверждения. Граница проверена на местном офлайн-примере с физической страницей РЭ БКД-ПК-RF.2.
5. Доверие к источнику ограничивает поступление байтов. Оно не превращает технический текст в системную инструкцию и не подтверждает применимость любой фразы ко всем поколениям оборудования. Для цитаты сохраняются область, точная редакция и физическая страница. В нормативных DS-EC-03 и DS-EC-05 требования к квалификаторам, независимому подтверждению и противоречивым сведениям остаются в силе.
