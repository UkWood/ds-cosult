# DS-консультант — Project Charter v0.1

Дата: 2026-11-17. Статус: проектные границы приняты владельцем; рабочий документ.

## Миссия
Создать технического собеседника для сайта МНПП «Сатурн»: естественный диалог, понимание оборудования и взаимосвязей, объяснения и рекомендации с подтверждением существенных технических утверждений.

## Независимость
DS-консультант — самостоятельный проект. Репозиторий NEW RAG `UkWood/LLM-RAG-chat-bot` — исключительно источник инженерного опыта, без изменения, переноса архитектуры или кода без разрешения. Источник сайта `UkWood/Saturn-Main-Site` — строго READ-ONLY. До отдельного решения не начинать production, интеграцию, обучение или fine-tuning локальной модели.

## Роли и контроль
Architecture Session A — архитектура, постановка заданий, решения, review и приёмка. Coding Session B — только утверждённая ограниченная реализация. Каждая работа документируется самостоятельным scope, материалами проверки и единым списком замечаний BLOCKER/IMPORTANT/MINOR. Merge — исключительно после явного разрешения владельца. Отдельная ветка/PR для документов и кода, кроме начальной инициализации пустого репозитория.

## GitHub как долговременная память
`UkWood/ds-cosult` — основной регистр истории, требований, исследовательских выводов, статусов, задач, отчётов и исходных кодов. Важное решение имеет идентификатор, дату, статус, обоснование, альтернативы и ссылки на доказательства. `docs/status/PROJECT_STATE.md` — точка входа для новой сессии; `docs/history/ARCHITECTURE_LOG.md` — непрерывная хронология; `docs/decisions/` — принятые решения. Менять принятые решения через новые записи, а не тихо переписывать историю.

## Достоверность
Каждый значимый технический факт должен иметь первоисточник, версию, идентификатор и область применимости. Внешний веб-поиск не равнозначен доверенному корпусу. Технические отношения из миграционных упоминаний не считаются доказательством совместимости. Отсутствие сведений не равняется отсутствию функции.

## Конфиденциальность
Репозиторий сейчас PUBLIC. Секреты, непубличные сырые документы, закрытые Core-вопросы и эталоны не коммитить до смены режима доступа или организации закрытого хранилища. Публичные спецификации и обобщённый журнал статусов допустимы.
