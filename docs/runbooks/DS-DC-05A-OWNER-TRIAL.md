# DS-DC-05A · Локальный стенд владельца

## Подготовка и запуск

Команда независимой WSL-приёмки и отдельная команда запуска с точными пинами находятся в отчёте поставки. Приёмка проверяет исходники, прежний подлинный replay R1, текущие тесты и стенд с MockTransport в сетевом namespace. Она экспортирует один ZIP в `C:\DS-Validation\Reports`. [Отчёт поставки и команды](../handoffs/DS-DC-05A-HANDOFF.md)

В WSL используются уже подготовленные сайт, Python 3.12 и кэш. Стенд проверяет материалы и доступность локального порта перед активацией. Запуск без `--live` показывает офлайн-режим. После принятия поставки `--live` запускает подтверждение `LIVE`, однократный выбор лимита в USD и один скрытый ввод ключа. Адрес стенда — `http://127.0.0.1:8765`. В live откройте локальную ссылку, напечатанную в терминале. Она содержит код доступа текущего запуска. После истечения сессии эта же ссылка открывает новую. Остановка — **Ctrl+C** в терминале запуска. Команда повторного запуска та же. Данные вопроса, запуск браузера, обновление вкладки, новый диалог и переключение режима отображения сами не вызывают DeepSeek.

## Диалог и экспертная оценка

1. Введите технический вопрос и нажмите «Отправить». При неоднозначности выберите изделие из каталога. При превышении лимита можно явно выбрать основное руководство и отправить уточнённый запрос.
2. В режиме посетителя видны проверенный ответ и ссылки. В экспертном режиме отдельно видны проект модели A, фактический ответ B, причины исключения утверждений и телеметрия. A предназначен для сверки.
3. Сохраните оценку и комментарий рядом с запросом. Новая редакция комментария добавляется отдельной записью. Явный экспорт создаёт очищенный Markdown-файл в `C:\DS-Validation\Reports`.
4. Новый диалог сбрасывает контекст. Обновление вкладки сохраняет действующую локальную сессию. Просроченная локальная сессия открывается без прежнего контекста.

## Расходы и данные

Оценка токенов показывает локальный размер. Перед отправкой система резервирует до 324 404 микроUSD на chat по заявленному пределу модели и добавляет 225 микроUSD за каждую физическую страницу новых загрузок. Это консервативный расчёт допуска по закреплённым пиковым ставкам. Известный usage, резерв и неопределённое начисление видны отдельно. Состояние стенда и журнал хранятся в `$HOME/.local/state/ds-dc05a/`. Ключ остаётся в памяти процесса.

При неизвестном начислении стенд блокирует новые платные операции, в том числе после перезапуска. Для продолжения нужна сверка с Architecture Session A и фактическими начислениями. [DeepSeek Usage](https://platform.deepseek.com/usage)

Покрытие пилота — **БКД-ПК-RF.2** (4 PDF, 80 физических страниц) и **СЛДКС-1** (10 уникальных PDF, 403 страницы). Ссылки на недоступные и исключённые материалы обозначены в каталоге. Полный набор СЛДКС-1 может превышать EXTENDED. Стенд принимает явный выбор основного руководства, сохраняя пометку об ограниченной области.
