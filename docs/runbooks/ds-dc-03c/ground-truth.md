# DS-DC-03C · Независимые источники для предлагаемого benchmark

Вход генератора получает только естественные вопросы, историю и закреплённое досье. Файл предназначен для проверки человеком.

| Вопрос | Независимая опора |
|---|---|
| Q01-N | Закреплённый отдельно эталон DC-03B. |
| C-MASS, C-IF | Карточка БКД-ПК-RF.2 в pinned site, поля `specs` и `interfaces`. Проверить редакцию руководства в WSL. |
| C-POWER, C-ENV | Карточка БКД-ПК-RF.2, поля `specs` и `power`. Условия и допустимость инструкций требуют сверки оригинала. |
| C-SLD | Абзац о назначении на pinned карточке СЛДКС-1. |
| C-SLD-OP | Раздел общих сведений на карточке СЛДКС-1. GT по деталям работы pending до сверки полного досье. |
| C-VARIANT, C-PRESERVE | GT pending до сверки обеих модификаций и применимых условий резервного питания по оригиналам. |
