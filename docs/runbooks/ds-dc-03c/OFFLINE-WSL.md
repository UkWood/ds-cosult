# DS-DC-03C · Независимая офлайн-приёмка WSL

Используйте чистый отдельный checkout согласованной ветки, содержащий исходный и итоговый коммиты. Подготовьте Python 3.12 с закреплёнными зависимостями из `requirements-dev.txt`, Git, `prlimit` и Poppler. Для системной сетевой изоляции нужны `unshare`, `ip` и разрешённые WSL user/network namespaces. Подготовка checkout и зависимостей выполняется отдельно. Повторно используйте локальные входы DC-03B. Кэш включает `audit.json`, токенизатор и 14 правильных оригиналов. Файл `q01-candidate.json` берётся из ранее сохранённого Audit Package. [Прежние локальные входы](../ds-dc-03b/OFFLINE-WSL.md)

Укажите проверенный reviewer точный итоговый SHA как `DS_DC_ACCEPT_SHA`. Используйте ранее заданные `SATURN_SOURCE`, `DS_DC_CACHE` и `DS_DC_Q01_CANDIDATE`. Из checkout, с уже активированным окружением, выполните одну строку:

```bash
bash scripts/validation/validate-dc03c.sh --commit "${DS_DC_ACCEPT_SHA:?укажите проверенный итоговый SHA}" --site "${SATURN_SOURCE:?укажите закреплённый checkout Saturn}" --cache "${DS_DC_CACHE:?укажите кэш DC-03B}" --fixture "${DS_DC_Q01_CANDIDATE:?укажите подлинный Q01}" --output /mnt/c/DS-Validation/Reports
```

Опциональные повторяемые аргументы `--extra-tests /absolute/path/test_independent.py` и `--protected-file /absolute/path/file` добавляют локальные проверки reviewer и сверку контрольной суммы явно указанного файла. Независимые тесты должны быть заранее просмотрены и использовать только разрешённые локальные материалы. `--network namespace` требует сетевой namespace, а `--network python` выбирает совместимый Python socket guard; по умолчанию `auto` фиксирует доступный вариант. Python guard препятствует внешним обращениям через Python socket API, включая Python-подпроцессы. Это ограничение не распространяется на прямые системные вызовы сторонних бинарников.

Runner формирует отдельный закрытый каталог для сырых результатов, JUnit, логов и ошибок. ZIP содержит Markdown Final Acceptance, сводку и результаты по этапам, screening и SHA256SUMS. Он создаётся и при обычных отказах preflight или тестов, код выхода 1. Пакет сохраняет сведения о доступных независимых проверках. Отсутствие подлинного Q01 блокирует полный итоговый PASS. ZIP проходит screening, сверку CRC и контрольных сумм до записи результата в выделенную папку. Если перенос отклонён, приватный каталог и код ошибки остаются доступны в WSL. Имена ZIP уникальны, результаты ранних прогонов сохраняются.

Просмотрите ZIP и передайте один файл. Reviewer сверяет пин и отдельно подтверждает R01-A/B/B-positive/C1/C2/C-applicability, контекст публикации, отсутствие внешних операций, обе исторические матрицы, Q01/Q02 wire, 5/5 supported подлинного Q01 и проверяемую связь новых выдержек с источниками. Новый отвечающий V2-кандидат реальной модели отсутствует. [Решение об автоматизации](../../architecture/A-DS-DC-10-AUTOMATED-VALIDATION-WORKFLOW.md)
